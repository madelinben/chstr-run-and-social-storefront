# Context — ubiquitous language

One row per domain noun, one spelling. Every doc, rule, identifier and UI label reuses it (`naming.mdc`).

| Term | Meaning |
|---|---|
| Session | The weekly CHSTR run and social: Mondays 18:30 at The Architect, always free. Not “event”. |
| Waiver | The form a new runner signs before their first session. Hosted on Jotform, linked from `/waiver`. |
| Product | A merchandise item staff manage in Shopify, with variants (sizes) and a price. Not “item” or “merch”. |
| Cart | The visitor’s chosen product variants, held by Shopify; the browser keeps only the cart id in `localStorage`. Not “basket”. |
| Order | A paid Shopify order. Staff manage it in Shopify admin or the Shopify mobile app. |
| Pickup | Customer collects an order at the next session via Shopify local pickup. No delivery. |
| Staff | Club organisers with a Shopify staff login. |
